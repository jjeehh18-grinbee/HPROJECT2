# 마이 팜 · 디지털 팜 다이어리 + AI

HTML, CSS, JavaScript만 사용하는 정적 웹사이트입니다. 설치나 빌드가 필요하지 않습니다.

## 실행

`index.html`을 브라우저에서 열어주세요. 기록은 같은 브라우저의 localStorage에 저장됩니다. 파일 직접 실행 시 브라우저 설정에 따라 페이지 사이 저장소 공유가 제한될 수 있으므로, 이 경우 Vercel에 정적 사이트로 배포해 확인해주세요. Vercel에서는 프레임워크를 Other로 선택하고 빌드 명령 없이 프로젝트 루트를 배포하면 됩니다.

처음 접속할 때 샘플 기록 8건을 만듭니다. 모든 기록을 삭제한 경우 샘플을 다시 만들지 않습니다. 브라우저의 사이트 데이터를 지우면 기록이 없어집니다. Supabase Auth로 이메일 회원가입, 로그인, 로그아웃 및 세션 확인을 처리합니다. 팜 다이어리 데이터는 아직 데이터베이스에 저장하지 않고 브라우저에 저장합니다.

## 파일 수정 안내

- `index.html`: 투데이 팜
- `write.html`: 팜 다이어리 작성 및 수정
- `list.html`: 목록, 검색, 날짜·작업 종류 필터
- `detail.html`: 기록 상세 및 삭제
- `report.html`: 기간별 리포트 및 질문창
- `auth.html`: 이메일 로그인 및 회원가입
- `style.css`: 색상, 글자, 레이아웃, 모바일 디자인
- `mock.js`: 샘플 기록과 날짜별 테스트 날씨
- `supabase-client.js`: Supabase 프로젝트 설정과 클라이언트 초기화
- `auth.js`: 회원가입 및 로그인 화면 동작
- `auth-guard.js`: 기존 화면의 세션 확인 및 로그아웃 동작
- `app.js`: 공통 메뉴, 화면 내용, 저장·검색·수정·삭제, 리포트 계산
- `assets/aifarm.png`: 감귤 농장 SVG 플레이스홀더

각 HTML은 공통 스크립트를 불러옵니다. 화면의 문구와 구성을 바꾸려면 `app.js`의 `homePage`, `writePage`, `listPage`, `detailPage`, `reportPage` 함수를 찾아주세요.

## 테스트 데이터 안내

날씨는 날짜별로 일정한 값이 나오는 테스트 데이터입니다. 기록에 저장한 날씨는 작업 내용을 수정할 때 유지하고, 작업일을 변경하면 해당 날짜의 테스트 날씨로 바뀝니다.

리포트는 오늘을 포함한 최근 7일, 30일 또는 최초 기록일부터 오늘까지 집계합니다. 환경 요약은 해당 기간의 일별 테스트 날씨를 사용하며 같은 날의 작업을 여러 번 기록해도 날씨를 중복 집계하지 않습니다.

AI 소식과 질문 답변은 실제 AI가 아닌 저장된 기록을 계산하는 체험 기능입니다. 질문에 포함된 `최근 한 달`, `30일`, `7일`, `일주일`, `전체`를 우선 적용하며, 기간이 없으면 선택한 리포트 기간을 사용합니다. 마지막 작업일은 전체 기록에서 찾습니다. 자유 질문 전체를 이해하는 기능은 아직 연결하지 않았습니다.
